# 나의 고교생활 (안드로이드 앱)

고등학생을 위한 수행평가·시험 일정, 내신 등급, 활동 기록 관리 앱입니다.
끝내지 않은 일정은 **마감 전날 밤 8시**와 **당일 아침 7시**에 폰 알람이 울립니다.

## APK 받는 법
1. 이 저장소의 **Actions** 탭에서 "APK 빌드"가 초록색 체크로 끝났는지 확인합니다.
2. 오른쪽 **Releases** → 최신 버전 → `school-life.apk` 를 폰에서 내려받습니다.
3. 설치할 때 "출처를 알 수 없는 앱" 허용을 한 번 켜 줍니다.

## 고치는 법
- 화면과 기능은 모두 `www/index.html` 한 파일에 있습니다.
- 이 파일을 고쳐서 main 브랜치에 올리면 자동으로 새 APK가 빌드됩니다.
- 새 APK는 기존 앱 위에 그대로 덮어 설치하면 기록이 유지됩니다.

## 주의
- `native/school-life.jks` 는 앱 서명 키입니다. 지우거나 바꾸면 업데이트 설치가 안 되고 앱을 지웠다 다시 깔아야 하므로(기록 삭제) 그대로 두세요.
